# Showcase Bot (Geode mod)

Termux: run  bash termux-build.sh  (does everything below automatically)

Build (no setup needed):
1. Create a free GitHub repo and upload everything in this folder.
2. Open the Actions tab -> "Build Mod" -> Run workflow.
3. When it finishes, download "Build Output" -> you get showcasebot.geode.

Install:
- PC: put the .geode in  <Geometry Dash>/geode/mods/
- Android: put it in Android/media/com.geode.launcher/game/geode/mods/
- iOS: install via the Geode launcher.

Use: open a level, tap On. First time it records; finish the level and it saves.
Tap On again later to replay. Tap Del to delete the saved run.
